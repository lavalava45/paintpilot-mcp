## 5. Профиль — часть состояния сессии, а не общая настройка COS

Код `3689249` в `src/core/guard/session-store.ts` (строки ~2630–2632) вычисляет профиль так:

```ts
const paintingProfile = textOrUndefined(input?.painting_profile)?.toLowerCase()
  ?? existing?.painting_profile
  ?? 'nontrivial_painting';
```

Когда для новой сессии выбран `nontrivial_painting`, в начальном состоянии устанавливается `construction_policy: 'enforced'` (~2739–2742).

- Первый город фактически имел `simple_graphic` без enforced.
- Более поздний запрос о кинематографической железнодорожной платформе получил `nontrivial_painting` и enforced.
- Это **разные художественные запросы**, а не контролируемый тест версии. Нельзя делать вывод, что художественная регрессия доказана только из-за этих разных профилей.
- **Не менять глобальный default** на `simple_graphic` и не добавлять указаний COS, если цель — восстановить исторические исходники без изменений.
- Для **точного повторного теста первого розового города** можно при инициализации **нового** art run *явно* передать `painting_profile: 'simple_graphic'`; только это обеспечивает совпадение важного исторического параметра. Существующий art run не понижать: код запрещает downgrade.
- Это настройка **отдельного тестового запуска**, а не новая художественная политика на все будущие задания.
