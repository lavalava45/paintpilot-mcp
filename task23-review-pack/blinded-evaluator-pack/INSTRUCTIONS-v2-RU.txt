Task 23 — повторная независимая слепая оценка, правило v2

Оценивайте только изображения ДО/ПОСЛЕ и указанный для кейса визуальный target/style contract.
Не пытайтесь угадать, какой кейс положительный или контрольный.

Для каждого case-01 … case-05 ответьте на все 8 вопросов только:
ДА / НЕТ / НЕ УВЕРЕН / НЕ ПРИМЕНИМО.

НЕ ПРИМЕНИМО разрешено только тогда, когда сам target/style contract действительно делает критерий
неприменимым. Если критерий применим, но по изображениям трудно решить, используйте НЕ УВЕРЕН.
Для каждого ответа НЕ ПРИМЕНИМО кратко укажите причину в n_a_reasons.

Не считайте количество ответов ДА. Итоговое правило применяется после получения формы:
для representational positive case каждый применимый обязательный критерий должен быть ДА.
Критерий, явно требуемый target contract, нельзя переводить в НЕ ПРИМЕНИМО.

Заполните evaluator_id, review_date и independence_attestation.
Не используйте технические логи, сведения о способе построения кейса, ожидаемые ответы или
приватную таблицу соответствий кейсов.
