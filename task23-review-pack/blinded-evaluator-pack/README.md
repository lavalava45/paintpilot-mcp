# Task 23 — пакет для независимой слепой оценки

Перед вами пять пар изображений «ДО / ПОСЛЕ». Оценивайте только сами изображения и описание визуальной цели / стиля в `evaluator-manifest.json`.

Не используйте историю репозитория, заметки автора, технические логи, идентификаторы операций, файлы вне этого пакета или любые сведения о том, какой результат считается ожидаемым.

Для каждого кейса ответьте на восемь заранее заданных вопросов в `review-form.blank.json`, используя варианты `ДА`, `НЕТ`, `НЕ УВЕРЕН`, а где это допустимо — `НЕ ПРИМЕНИМО`.

При необходимости можно добавить короткое визуальное наблюдение. Не пытайтесь угадывать, какими инструментами или способом были созданы изображения.

Оценщик должен быть независим от процесса создания и предыдущей проверки этих изображений и получить только этот пакет.
